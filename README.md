Desarrollador y especialista en logística. Construyo **[Diler](https://www.dilerlatam.com)**, una plataforma que conecta personas, repartidores y comercios sin intermediarios, diseñada para escalar en Latinoamérica.

- Producto y desarrollo en **Koder SpA**: web apps con TypeScript, Next.js, React y PostgreSQL.
- Fondo en **logística y gestión de inventarios**: almacenamiento, control de stock, seguimiento de distribución, planificación y despacho.
- **Análisis de datos** aplicado a operación: Power BI, DAX, Power Query y Python.
- Fuera del teclado: skateboarding y ajedrez.
